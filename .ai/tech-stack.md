Frontend - ASP.NET Core Razor Pages:

Razor Pages pozwala na szybkie tworzenie stron i prostych widokow w oparciu o model MVC
ASP.NET Core zapewnia wydajnosc i stabilnosc aplikacji webowych
C# umozliwia bezpieczne i czytelne modelowanie logiki po stronie serwera
Wbudowany system formularzy i walidacji ulatwia tworzenie paneli CRUD

Backend - ASP.NET Core + Entity Framework Core:

ASP.NET Core obsluguje routing, middleware oraz logike aplikacji po stronie serwera
Entity Framework Core zapewnia mapowanie obiektowo-relacyjne i migracje bazy
SQL Server jako relacyjna baza danych dla danych aplikacji
ASP.NET Core Identity zapewnia autentykacje i zarzadzanie uzytkownikami

AI - Komunikacja z modelami przez usluge Openrouter.ai:

Dostep do szerokiej gamy modeli (OpenAI, Anthropic, Google i wiele innych)
Pozwala na ustawianie limitow finansowych na klucze API
Umozliwia szybka zmiane modelu bez przebudowy aplikacji

Testowanie - Klasyczny framework dla .NET i Razor Pages:

xUnit jako standardowy framework do testow jednostkowych w .NET
Microsoft.AspNetCore.Mvc.Testing do testow integracyjnych dla aplikacji ASP.NET Core
